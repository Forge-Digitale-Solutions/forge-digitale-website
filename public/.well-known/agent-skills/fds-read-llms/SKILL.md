# Lire llms.txt FDS

## When to use

Cartographier les pages publiques (création site, maintenance, Linux, montage PC, blog, légal).

## How

1. `GET https://forgedigitalesolutions.com/llms.txt`
2. Suivre les liens listés ; pour une page HTML, préférer `Accept: text/markdown` si supporté.
3. Sitemap : `https://forgedigitalesolutions.com/sitemap.xml`

## Out of scope

Pas d'API mutable ; devis = contact humain.
