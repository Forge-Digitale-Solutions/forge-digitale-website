# Clics et impressions Search Console : ce que ça veut dire

Vous ouvrez la Search Console. Un graphique. Quatre chiffres. Et souvent la même question : « Est-ce que ça veut dire que ça marche ? »

Je m’appelle Anthony Marcelin. Je crée des sites depuis Saint-Laurent-Médoc. Sur les projets que je suis, j’ouvre le rapport Performances pour voir ce que Google montre réellement : pas pour « optimiser un classement », pour savoir si le site apparaît, sur quelles pages, et si quelqu’un clique.

Voici comment je lis ces chiffres.

*Source : [Aide Search Console – Rapport sur les performances](https://support.google.com/webmasters/answer/7576553?hl=fr)*

## Les quatre métriques

**Impressions.** Combien de fois un lien vers votre site est apparu dans les résultats Google (Recherche, et selon le rapport Discover / Actualités). Pour un lien classique, l’impression peut compter même si le résultat n’était pas encore dans la zone visible de l’écran, tant que la page de résultats est ouverte et qu’il n’a pas fallu cliquer « afficher plus » pour le voir.

**Clics.** Combien de fois quelqu’un a quitté Google pour arriver sur votre site via ce lien. Revenir en arrière puis recliquer sur le *même* lien ne compte qu’une fois. Cliquer un autre lien compte à part.

**CTR.** Clics divisés par impressions. Un CTR bas avec beaucoup d’impressions, ça veut souvent dire : le titre / l’extrait n’incite pas au clic, ou la requête ne correspond pas à la page.

**Position moyenne.** Moyenne de la meilleure position de votre site (ou de la page) quand il a reçu une impression. Ce n’est pas « vous êtes toujours 4e ». Une même requête peut vous placer autrement selon le lieu, l’appareil ou l’historique. Google le dit : ne tirez pas de conclusion hâtive sur un numéro seul.

*Source : [Aide Search Console – Que sont les impressions, les clics et la position ?](https://support.google.com/webmasters/answer/7042828?hl=fr)*

## Graphique et tableau : pourquoi les totaux divergent

Le **graphique** agrège souvent par *propriété* (le site). Deux résultats du même site pour une requête = une impression dans le total du graphique.

Le **tableau**, selon l’onglet, agrège autrement. Onglet Pages : chaque URL compte séparément. Les totaux graphique / tableau peuvent donc différer. Ce n’est pas forcément une erreur du presta ou de Google : c’est le mode d’agrégation.

Quand on vous montre une capture, demandez la même vue (même période, même filtre, même onglet) avant / après. Sinon vous comparez deux choses différentes.

Les données les plus récentes peuvent être **préliminaires** (ligne en pointillés) : elles bougent encore quelques heures.

*Source : [Aide Search Console – Rapport sur les performances](https://support.google.com/webmasters/answer/7576553?hl=fr)*

## Ce que ces chiffres ne disent pas

Ils ne disent pas « vous êtes 1er demain ». Google rappelle qu’il n’y a pas de secret pour être premier, et qu’une modification peut mettre des heures… ou des semaines à se voir.

Une hausse d’impressions sans clics n’est pas une victoire commerciale. Une position moyenne qui bouge de 0,3 point non plus. Regardez plutôt : quelles **pages**, quelles **requêtes**, sur quelle période.

Si un presta vous vend un classement magique à partir de ces seuls totaux, relisez la checklist : [On m’a proposé du référencement : que vérifier avant de payer](/blog/referencement-verifier-avant-de-payer/).

*Source : [Google Search Central – Bien débuter en référencement naturel](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?hl=fr)*

## Comment je m’en sers sur un site

1. Période claire (28 jours ou 3 mois), type de recherche Web.
2. Onglet Pages : quelles URL ont des impressions ? Des clics ?
3. Onglet Requêtes : quelles formulations amènent (ou n’amènent pas) du trafic.
4. Une page avec des impressions et zéro clic : title / contenu à reprendre, ou page pas au bon sujet.
5. Zéro impression sur une page importante : d’abord vérifier si Google la voit (inspection d’URL, indexation). J’ai détaillé le cas « site en ligne, personne ne le trouve » ici : [Mon site est en ligne. Personne ne le trouve.](/blog/site-en-ligne-introuvable-google/).

Pas besoin d’être « référenceur » pour ça. Il faut un accès Search Console (au moins en lecture) et regarder les mêmes écrans deux fois.
